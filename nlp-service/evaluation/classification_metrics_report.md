# News Category Classifier Evaluation

Generated by `evaluation/evaluate_classification.py`. Metrics below are measured, not invented, on a held-out test split of `sample_news_categories.csv` (40 rows — a demo/sample dataset; see DATASET_SETUP.md).

No transformer-based comparison is included for this task: this project does not bundle or fetch a pretrained financial news-category transformer model. The classifier's rule-based confidence backstop (classification.py) is a fallback for low-confidence predictions, not a second model to benchmark against.
